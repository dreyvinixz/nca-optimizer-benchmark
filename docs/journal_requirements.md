# Journal Requirements

Target journal:

```text
Neural Computing and Applications
Springer Nature
```

Submission type:

```text
Original Article
```

The final article should use the Springer Nature journal template, not the LNCS
conference template.

Recommended LaTeX class:

```latex
\documentclass[pdflatex,sn-mathphys-num]{sn-jnl}
```

## Double-Blind Requirements

Prepare:

- anonymous manuscript
- separate title page
- data availability statement
- code availability statement
- competing interests statement
- funding statement
- author contributions

## Scientific Completeness

Before submission, the project should include temporal validation, equal
optimizer budget, multiple seeds, convergence analysis, runtime analysis,
statistical tests, financial backtesting, and paper-ready figures/tables
generated from saved outputs.
