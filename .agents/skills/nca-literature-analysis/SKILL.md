# NCA Literature Analysis Skill

Use this skill when searching, reading, synthesizing, or extracting citations from the project's reference repository (`article/references/md_references/`).

## 1. Reference Repository Map

- `article/references/md_references/nca_journal_521_2024_plus/`: 40 recent (2024–2026) papers published in Neural Computing and Applications.
- `article/references/md_references/nca_search_all/`: 40 topic search papers (metaheuristics, financial ML, optimizer benchmarks).
- `article/references/md_references/literature_all/`: 5 core metaheuristic surveys (Gad 2022, Rajwar 2023, Faris 2018).
- `article/references/md_references/s00521_2025_11546_2_nca_benchmark.md`: Primary NCA benchmark paper (Dhingra et al. 2025).
- `article/references/md_references/ijcnn_precursor_paper.md` & `ijcnn_deep_learning_ga_paper.md`: Research group precursor papers (Souza et al. 2025, 2026).

## 2. Best Practices for Citation Extraction

1. **Verify DOIs**: Always cross-reference BibTeX entries with `article/manuscript/references.bib`.
2. **Prioritize Recent NCA Papers**: When defending methodology choices, cite 2024–2026 NCA papers to show alignment with the journal's current state of the art.
3. **Compare Limitations**: Frame literature gaps in terms of missing equal-budget benchmarks, data leakage in temporal splits, and absence of trading backtests.
