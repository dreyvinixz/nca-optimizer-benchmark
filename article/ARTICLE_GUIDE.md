## 3. LaTeX Template Rules

- **Document class**: `\documentclass[sn-mathphys-num,Numbered]{sn-jnl}`
- **Bibliography style**: `sn-mathphys-num.bst` (numbered references `[1]`, `[1-3, 7]`)
- **Template files**: Download from https://www.springernature.com/gp/authors/campaigns/latex-author-support
- **Figures**: EPS (vector, 1200 dpi) or TIFF (halftone, 300 dpi)
- **Figure naming**: `Fig1.eps`, `Fig2.tiff`, etc.
- **Figure typography**: Sans-serif (Helvetica/Arial), 8–12 pt
- **Tables**: Numbered with Arabic numerals, cited in order
- **Headings**: Decimal system, max 3 levels
- **Math**: Use `amsmath` package

## 4. What the Article MUST Contain

### Content Requirements
- [ ] Clear research gap (no controlled benchmark for financial optimizer comparison)
- [ ] Systematic related work with recent NCA papers (last 3–5 years)
- [ ] Temporal validation protocol (no data leakage)
- [ ] Equal optimizer budget (same number of fitness evaluations)
- [ ] Multiple random seeds (prototype: 5; final: 20–30)
- [ ] Comprehensive metrics: Accuracy, Balanced Accuracy, F1, MCC, AUC-ROC, AUC-PR
- [ ] Convergence curves (best fitness vs evaluations)
- [ ] Runtime analysis
- [ ] Statistical tests: Friedman, Wilcoxon-Holm, effect sizes
- [ ] Financial evaluation: Sharpe ratio, MDD, profit factor
- [ ] Data/code availability statement
- [ ] Reproducible configuration files (YAML)

### Submission Requirements
- [ ] Anonymous manuscript (no author names/affiliations in main.tex)
- [ ] Separate title page with all author info
- [ ] Abstract: 150–250 words
- [ ] Keywords: 4–6
- [ ] All figures cited in text in sequential order
- [ ] All tables cited in text in sequential order
- [ ] Generative AI disclosure (if used) in Methods section

## 5. What the Article MUST NOT Contain

### Framing Errors
- ❌ "We improved a previous GA-based model by adding PSO"
- ❌ Framing as incremental improvement of a single optimizer
- ❌ Comparing optimizers with different evaluation budgets
- ❌ Using accuracy alone as the primary metric

### Methodological Errors
- ❌ Shuffled data split (temporal order must be preserved)
- ❌ Test data used in fitness evaluation (data leakage)
- ❌ Comparing GA by generations and PSO by iterations directly
- ❌ Claims without statistical support

### Submission Errors
- ❌ Author names in the main manuscript (double-blind)
- ❌ Self-identifying citations ("In our previous work [Author, Year]...")
- ❌ Undefined abbreviations in abstract
- ❌ References to unpublished/inaccessible data

## 6. Correct Framing

### Article Positioning
> We conduct a controlled benchmark of evolutionary and swarm intelligence
> optimizers for neural intraday trend classification under real-world
> financial constraints.

### Connection to Previous Work
> A previous conference version investigated feature selection for Random
> Forest models using Brazilian mini-index futures [anonymous]. A subsequent
> extension explored GA-based hyperparameter optimization for RF, SVM, and
> MLP models [anonymous]. The present study substantially extends this line
> by shifting the focus from a single optimizer to a controlled benchmark of
> optimizer families, adding temporal validation, convergence analysis,
> statistical testing, and financial evaluation.

## 7. Reproducible Writing Model

Every claim in the article must be traceable:

| Claim Type | Source |
|---|---|
| Experimental result | CSV in `outputs/metrics/` or `outputs/tables/` |
| Figure | Generated by script in `scripts/09_generate_paper_figures.py` |
| Configuration | YAML in `config/` |
| Statistical test | Output in `outputs/statistical_tests/` |
| Financial metric | Output in `outputs/backtests/` |
| Previous result | PDF in `article/references/` |

### Traceability Chain
```
config/experiment_config.yaml
  → scripts/02_run_random_search.py (etc.)
    → outputs/metrics/*.csv
      → scripts/09_generate_paper_figures.py
        → article/figures/*.eps
          → article/manuscript/sections/results.tex
```
