# NCA manuscript — Overleaf upload package

This is the full current manuscript source package, including the asymptotic search-overhead discussion, practical candidate-fit figure, and the clarification that the 95% effort threshold is based on validation-fitness gain rather than test performance.

## Upload to Overleaf

1. In Overleaf, choose **New Project → Upload Project** and upload this ZIP.
2. Set `main.tex` as the main document and select **pdfLaTeX**.
3. Compile. The project includes the Springer Nature class, bibliography styles, bibliography database, all manuscript sections, and every referenced PDF figure.
4. `titlepage.tex` is provided separately for the title-page workflow. Keep it separate from the anonymized manuscript during double-blind review; it is not included from `main.tex`.

The ZIP contains editable sources only; it does not include compilation auxiliaries or the generated manuscript PDF.
