\section{Materials and Methods}\label{sec:materials_methods}

This section formulates the materials, dataset generation, model configuration, optimization algorithms, performance evaluation metrics, and diagnostic ablation analyses, following the structural framework established by Al Bannoud et al. \cite{al_bannoud2026accelerating}.

\subsection{Dataset Generation and Technical Feature Selection}\label{sec:dataset}

The empirical evaluation is conducted on high-frequency intraday price records of the Mini-Index futures contract (symbol: WIN), traded on B3 (Brazilian Stock Exchange). The dataset originates from the BovDB repository \cite{cardoso2022bovdb, souza2024dataset} and spans consecutive bimonthly contract maturities—specifically WING24 (February), WINJ24 (April), WINM24 (June), and WINQ24 (August)—sampled at a granular 5-minute candle frequency.

To preserve continuous microstructural price patterns without introducing artificial volatility gaps, data from adjacent overlapping contracts are tracked across transition windows based on trading volume dominance. The complete benchmark dataset comprises $N = 15,057$ clean, consecutive 5-minute intraday bars. The target variable is formulated as a binary trend classification label $y_k \in \{0, 1\}$ at bar index $k$:
\begin{equation}\label{eq:target}
    y_k = \begin{cases} 1 \quad (\text{Uptrend}) & \text{if } P_{k+1} > P_k, \\ 0 \quad (\text{Downtrend}) & \text{if } P_{k+1} \le P_k, \end{cases}
\end{equation}
where $P_k$ denotes the closing price at 5-minute bar $k$. Across the 15,057 total instances, the target distribution comprises approximately 49.2\% uptrend ($y=1$) and 50.8\% downtrend ($y=0$) instances.

To filter out redundant attributes, Information Gain feature selection \cite{souza2025iccsa} is applied to an initial pool of 66 technical indicators:
\begin{equation}\label{eq:infogain}
    I(Y; X_j) = H(Y) - H(Y \mid X_j) = \sum_{y \in Y} \sum_{x \in X_j} p(x, y) \log_2 \left( \frac{p(x, y)}{p(x) p(y)} \right).
\end{equation}
The top $d=7$ Information Gain features are selected to form the input feature vector $\bm{x}_k \in \mathbb{R}^7$. Figure~\ref{fig:workflow} presents an overview of the complete methodological workflow, mirroring Figure 1 in Al Bannoud et al. \cite{al_bannoud2026accelerating}.

\subsection{Machine Learning Model Training and Evaluation}\label{sec:training}

To prevent temporal look-ahead leakage, we enforce a strict 60/20/20 sequential chronological split protocol with no shuffling (\texttt{shuffle = false}). The 15,057 intraday bars are partitioned sequentially along the time axis:
\begin{enumerate}
    \item \textbf{Training Set ($\mathcal{D}_{\text{train}}$)}: The first 60\% of chronological bars ($N_{\text{train}} = 9,034$ instances) for optimizing neural network connection weights.
    \item \textbf{Validation Set ($\mathcal{D}_{\text{val}}$)}: The subsequent 20\% of chronological bars ($N_{\text{val}} = 3,011$ instances) for candidate fitness evaluation $f(\bm{\theta})$.
    \item \textbf{Out-of-Sample Test Set ($\mathcal{D}_{\text{test}}$)}: The final 20\% of chronological bars ($N_{\text{test}} = 3,012$ instances) strictly reserved for out-of-sample predictive and financial evaluation.
\end{enumerate}

\subsection{Hybrid Neural Optimization Benchmarking}\label{sec:hybrid}

The base classifier is a Multilayer Perceptron (MLP) trained using backpropagation with RMSprop optimization and binary cross-entropy loss. Given an input feature vector $\bm{x}_k \in \mathbb{R}^7$, the network maps market states to predicted trend probabilities $\hat{y}_k = P(y_k = 1 \mid \bm{x}_k)$.

Model performance depends on six hyperparameter boundaries comprising the candidate vector $\bm{\theta} = [n_{\text{hidden}}, lr, \alpha, p_{\text{drop}}, B, \text{ep}]^T \in \mathbb{R}^6$. \subsection{Optimization}\label{sec:optimization}

To eliminate budget inequality bias \cite{dhingra2025solar}, our benchmark protocol enforces a strict candidate evaluation cap of $N_{\text{eval}} = 1,500$ evaluations per random seed across all five optimizers:
\begin{equation}\label{eq:budget}
    \sum_{t=1}^{T_{\text{max}}} P_{\text{size}} = N_{\text{eval}} = 1,500.
\end{equation}

The five evaluated optimizer families implement distinct search mechanics over candidate positions $\bm{\theta}_i \in \mathbb{R}^6$:

\subsubsection{Random Search (RS)}
\begin{equation}\label{eq:rs}
    \bm{\theta}_i = \bm{L} + \bm{r} \odot (\bm{U} - \bm{L}), \quad \bm{r} \sim U(0,1)^6.
\end{equation}

\subsubsection{Genetic Algorithm (GA)}
\begin{equation}\label{eq:ga}
    \bm{\theta}_i^{(t+1)} = \bm{\theta}_i^{(t)} + \mathcal{N}(0, \sigma^2 \cdot (\bm{U} - \bm{L})).
\end{equation}

\subsubsection{Particle Swarm Optimization (PSO)}
\begin{equation}\label{eq:pso_v}
    \bm{v}_i^{(t+1)} = w \bm{v}_i^{(t)} + c_1 r_1 (\bm{p}_i - \bm{\theta}_i^{(t)}) + c_2 r_2 (\bm{g} - \bm{\theta}_i^{(t)}),
\end{equation}
\begin{equation}\label{eq:pso_x}
    \bm{\theta}_i^{(t+1)} = \bm{\theta}_i^{(t)} + \bm{v}_i^{(t+1)}.
\end{equation}

\subsubsection{Differential Evolution (DE)}
\begin{equation}\label{eq:de}
    \bm{v}_i^{(t+1)} = \bm{g}^{(t)} + F \cdot (\bm{\theta}_{r1}^{(t)} - \bm{\theta}_{r2}^{(t)}).
\end{equation}

\subsubsection{Grey Wolf Optimizer (GWO)}
\begin{equation}\label{eq:gwo}
    \bm{\theta}_i^{(t+1)} = \frac{\bm{\theta}_1 + \bm{\theta}_2 + \bm{\theta}_3}{3}.
\end{equation}

\subsection{Metrics for Performance Evaluation of Neural Models}\label{sec:metrics}

Candidate fitness $f(\bm{\theta})$ is evaluated on $\mathcal{D}_{\text{val}}$ using a compound objective combining Matthews Correlation Coefficient ($\operatorname{MCC}$) and $F_1$-score:
\begin{equation}\label{eq:fitness}
    f(\bm{\theta}) = 0.60 \times \operatorname{MCC}(\bm{\theta}) + 0.40 \times F_1(\bm{\theta}).
\end{equation}

\subsection{Improved Analysis on the Best Neural Optimizer}\label{sec:improved_analysis}

Following the diagnostic analysis design of Section 2.6 in Al Bannoud et al. \cite{al_bannoud2026accelerating}, we perform six structured ablation and diagnostic evaluations:

\subsubsection{Comparison with Gradient-Based Optimizer Algorithms}\label{sec:grad_comp}
Evaluates performance differences between population-based metaheuristic global search engines (GA, DE, PSO, GWO) and unguided Random Search baselines.

\subsubsection{Improvements in the Directional Trend Classifier}\label{sec:classifier_imp}
Measures out-of-sample classification metric gains achieved by compound MCC optimization over uncalibrated cross-entropy loss.

\subsubsection{Impact of Pipeline Design Choices on Trend Prediction Performance}\label{sec:pipeline_impact}
Assesses the structural impact of enforcing a sequential temporal split protocol (\texttt{shuffle = false}) versus randomized data shuffling.

\subsubsection{Ablations on Technical Input Features and Hyperparameter Subsets}\label{sec:ablations}
Quantifies predictive loss when restricting the feature dimension from $d=7$ to smaller indicator subsets.

\subsubsection{Permutation-Importance Analysis}\label{sec:importance}
Identifies the most critical technical features driving neural classification signals.

\subsubsection{Performance Variability Across Independent Runs}\label{sec:variability}
Evaluates stochastic stability and confidence intervals across 20 independent random seeds.
